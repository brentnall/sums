# Surrogates for Mortality in Cancer Screening Trials (SUMS)

## Introduction

This repository contains code and data arising from a systematic review (SUrrogates for Mortality in cancer Screening trials, SUMS). See: https://warwick.ac.uk/fac/sci/med/research/hscience/pet/screening/evidence/sums

## Repository Contents

- **1_cebp** : data and analysis code for a forthcoming publication:

LATE-STAGE OUTCOMES AS SURROGATES FOR MORTALITY IN CANCER SCREENING TRIALS: A SYSTEMATIC REVIEW AND META-ANALYSIS
Rebolj et al, To appear in *Cancer Epidemiology, Biomarkers & Prevention*
